サポート

ご質問、不具合の報告、機能のご要望：xlahuerta@protonmail.com。iOS と watchOS のバージョンを記載し、同期の問題の場合は使用しているサーバソフトウェアもお知らせください。パスワードは絶対に送らないでください。

はじめに（アカウント不要）

  1. iPhone に Folito をインストールします。Apple Watch 用アプリは iPhone の Watch App からインストールされます（または自動的にインストールされます）。Apple Watch を設定できるように、iPhone のアプリを一度開いてください。
  2. お持ちの .epub または無料のパブリックドメインの本を読み込みます。ライブラリで EPUBを読み込む（+）をタップするか、“ファイル”App または共有シートからファイルを開いて Folito を選択します。本は Apple Watch に送信されます。
  3. Apple Watch で Folito を開き、本を選択します。読んでいる位置は Apple Watch に保存され、オフラインで読書できます。

オプション：ほかの読書アプリと読書位置を同期

同期はデフォルトでオフで、KOReader や KOReader Sync プロトコルに対応したほかのアプリで同じ本の続きを読む場合にのみ必要です。iPhone で設定 › 進捗の同期を開き、サーバの URL と、そのサーバにすでにお持ちのアカウントのユーザ名とパスワードを入力します（アカウントはサーバ側で作成してください。たとえば KOReader では Tools › Progress sync › Register から作成できます。Folito はアカウントを作成しません）。保存して同期をオンにするをタップしてから、接続をテストをタップします。Apple Watch が単独で同期できるように、ログイン情報は Apple Watch に送信されます。

同期を停止するには、同期をオフにしてログイン情報を削除をタップします。ログイン情報が iPhone と Apple Watch から削除されます。本と読書位置は保持されます。

よくある質問

アカウントは必要ですか？

いいえ。本の読み込みと読書には、どのようなアカウントも必要ありません。同期はオプションで、あなたが選んだサーバを使用します。開発者はサーバを運営していません。

どのサーバが使えますか？

KOReader の公開サーバやセルフホストのサーバを含め、KOReader Sync（kosync）互換のサーバであればどれでも使えます。アプリはサーバを提供しません。

KOReader や Readest で進捗が一致しません。

すべてのデバイスで、変更されていない同じ EPUB ファイルである必要があります。Readest ではドキュメントの照合方法を File Content に、KOReader では Binary に設定してください。

http:// のサーバに接続できません。

iOS はインターネット上のホストへの暗号化されていない http 通信をブロックします。https を使用するか、ローカルネットワークのアドレスを使用してください（初回は iOS がローカルネットワークへのアクセス許可を求めます）。

単語の検索で「オフライン」または「見つかりません」と表示されます。

単語の検索にはネットワーク接続が必要で、Wiktionary（英語版）と、Wiktionary にない英単語については dictionaryapi.dev を使用します。定義は英語で表示されます。

アクセシビリティ

iPhone と Apple Watch のアプリは VoiceOver と大きな文字サイズ（Dynamic Type）に対応し、ダークモード、“コントラストを上げる”、“文字を太くする”に従い、独自のアニメーションは使用しません。Apple Watch では、読書テーマは WCAG のコントラスト比を満たしており、タイポグラフィ › システムの文字サイズに合わせるをオンにすると本文が Apple Watch の文字サイズに従います。

DRM で保護された本に対応していますか？

いいえ。
