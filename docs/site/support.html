Support

Questions, bug reports or feature requests: xlahuerta@protonmail.com. Please include your iOS and watchOS versions and, if the problem is syncing, which server software you use. Never send your password.

Getting started (no account needed)

  1. Install WristReader on your iPhone; the watch app installs through the Watch app on the iPhone (or automatically). Open the iPhone app once so the watch can be set up.
  2. Import an .epub you own or a free public-domain one: tap Import EPUB (+) in the Library, or open the file from the Files app or the share sheet and choose WristReader. The book is sent to your watch.
  3. Open WristReader on the watch and choose the book. Your place is saved on the watch, and reading works offline.

Optional: sync your place with other readers

Sync is off by default and only needed to continue the same book in KOReader or another app that speaks the KOReader Sync protocol. On the iPhone open Settings › Progress Sync, enter the server URL and the username and password of an account you already have on that server (create it on the server itself, for example in KOReader under Tools › Progress sync › Register; WristReader does not create accounts), tap Save and Turn On Sync, then Test Connection. The login is sent to your watch so it can sync on its own.

To stop syncing, tap Turn Off Sync and Remove Login: the login is removed from the iPhone and the watch; your books and reading positions are kept.

Frequently asked

Do I need an account?
No. Importing and reading need no account of any kind. Sync is optional and uses a server you choose; the developer runs no server.
Which servers work?
Any KOReader Sync (kosync) compatible server, including the public KOReader server and self-hosted ones. The app does not provide a server.
Progress does not match in KOReader or Readest.
It must be the same, unmodified EPUB file on every device. In Readest set the document matching method to File Content; in KOReader use Binary.
My http:// server does not connect.
iOS blocks plain http to internet hosts. Use https, or a local-network address (iOS asks for local network permission the first time).
Word lookup says offline or not found.
Lookup needs a network connection and uses Wiktionary (English edition), and dictionaryapi.dev for English words Wiktionary lacks; definitions are in English.
Accessibility
The iPhone and watch apps support VoiceOver and larger text sizes (Dynamic Type), follow Dark Mode, Increase Contrast and Bold Text, and use no custom animations. On the watch, reading themes meet WCAG contrast ratios and Typography › Match System Text Size makes the book text follow the watch's text size.
Does the app support DRM-protected books?
No.
