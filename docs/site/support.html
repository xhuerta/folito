Getting started

  1. Install WristReader on your iPhone; the watch app installs through the Watch app on the iPhone. Open the iPhone app once so the watch can be set up.
  2. Import an .epub: tap + in the app, or open the file from Files / the share sheet and choose WristReader. The book is sent to your watch.
  3. To sync progress, open Sync in the iPhone app, enter your KOReader Sync server URL, username and password, then tap Save & send to watch and Test connection.

Frequently asked

Which servers work?
Any KOReader Sync (kosync) compatible server, including the public KOReader server and self-hosted ones. The app does not provide a server.
Progress does not match in KOReader or Readest.
It must be the same, unmodified EPUB file on every device. In Readest set the document matching method to File Content; in KOReader use Binary.
My http:// server does not connect.
iOS blocks plain http to internet hosts. Use https, or a local-network address.
Word lookup says offline or not found.
Lookup needs a network connection and uses Wiktionary (English edition); definitions are in English.
Does the app support DRM-protected books?
No.
