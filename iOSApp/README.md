# Folito iOS app

SwiftUI, iOS 16+, target `Folito` (sources in `iOSApp/`, excluding `Tests/`; tests in `iOSApp/Tests`).

- The Info.plist is generated by XcodeGen from `project.yml` (`info.properties`), which declares the EPUB document types
  (`org.idpf.epub-container`) so the share sheet / "Open in" works. No entitlements are required.
- Pipeline: import (Files / share / onOpenURL) -> copy to temp (security-scoped) -> `EPUBParser` off main
  thread -> JSON -> LZFSE -> `Application Support/Folito/Books/<hash>.wrbook`.
- WatchConnectivity schema: `docs/WATCH_CONNECTIVITY.md`.
- KOSync credentials live in the Keychain; they are also sent to the watch (see doc for the tradeoff).
